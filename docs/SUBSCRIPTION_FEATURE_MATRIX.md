## Current Repair Notes

- The centralized frontend resolver now supports features, actions, named numeric limits, retention limits, export/analytics/realtime/notification/multi-admin/multi-branch categories, paid-plan checks, active trial access, and expired-trial restrictions.
- The backend global feature flag set now includes every feature advertised by the default estate, homeowner, and office plan catalog, including office-specific features and export/reporting flags.
- Estate plan inheritance text is non-circular in the backend catalog: Basic extends Starter features, Plus extends Basic, Growth extends Plus, Pro extends Growth, Enterprise extends Pro. The pricing UI mirrors that structure.
- Remaining PARTIAL rows mostly need page-level entitlement guards and dedicated tests, not new plan metadata.
